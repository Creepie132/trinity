## Флоу публикации объявления

### Шаг 0 — Проверить сессию
```
yad2_check_session()
```

### Шаг 1 — Собрать данные от Влада
Перед публикацией спросить всё что не указано:

**Основное:**
- Что продаём? (название товара — желательно на иврите)
- Категория (мебель / электроника / одежда / инструменты / авто / и т.д.)
- Цена в шекелях (или бесплатно?)
- Состояние: новое (חדש) или б/у (יד שניה)?
- Описание (можно на русском — переведу на иврит)

**Контакт:**
- Имя (как написать в объявлении)
- Телефон (формат: 054-1234567)

**Адрес:**
- Город (на иврите или русском)
- Улица (на иврите или русском)
- Номер дома

**Фото:**
- Есть ли фото? Если да — абсолютные пути к файлам JPEG/PNG
  (например: C:\Users\Lalka\Pictures\chair.jpg)

### Шаг 2 — Поиск категории
```
yad2_search_categories(query: "<товар на иврите>")
```
Выбрать наиболее подходящую categoryId и categoryText.

### Шаг 3 — Поиск города
```
yad2_search_city(query: "<город на иврите>")
```
Получить cityId. Ашкелон = אשקלון

### Шаг 4 — Поиск улицы
```
yad2_search_street(cityId: "...", streetQuery: "<улица на иврите>")
```
Получить streetId и addressMasterId.

### Шаг 5 — Публикация
```
yad2_publish_listing({
  title,           // заголовок на иврите
  description,     // описание на иврите
  categoryId,
  categoryText,
  city, cityId,
  street, streetId,
  addressMasterId,
  homeNumber,
  price,           // число, 0 = бесплатно
  conditionId,     // 1 = новое, 2 = б/у
  giveAway,        // true если бесплатно
  contactName,
  phone,
  imagePaths       // массив абсолютных путей к фото
})
```
